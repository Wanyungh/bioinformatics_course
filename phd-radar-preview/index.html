Quick actions

这个试用版会把你的 Save / Skip / Priority / Weekly Report 记录保存在当前浏览器 localStorage 中，刷新页面也会保留。

Hotspot Feed

热点不是“越多越好”，而是尽快判断哪些值得进入你的长期科研资产。

Inbox

Update 后的新信息先进入这里，快速做 Save / Deep Read / Skip 判断，不直接污染 Library。

Research Library

长期只保存真正值得回来的论文和资料。PDF Library 在完整部署版中作为 Library 的子视图。

Weekly Report Library

周报不是生成后消失，而是保存“当时你看到什么 + 当时怎么判断”。

Web Resources

把博士期间反复用到的数据库、protocol、专业工具放到同一入口，不再临时回忆“那个网站叫什么”。

Generate Weekly Report

本试用版会把当前未 Skip 的记录形成一份可搜索的内部周报并存档，用于测试你的工作流。正式版再连接实时 Watch / 自动检索与 Word 文件持久化。

Add Paper

试用版先测试“自己加文章 → 进入 Inbox → Save/Deep Read”的流程。正式部署版再接 Europe PMC / DOI / PMID 自动核验。
